# Context

Solo hobby project, no team.

## Setup
- Game: Starsector 0.98a-RC8 on a Windows PC (RAM is tight: 94-97% used during battles).
- Mod files live in `Starsector/mods/Claude Captain/`; runtime files in `saves/common/claude_captain/`.
- Enabled mods list: `Starsector/mods/enabled_mods.json` (edit only with game and launcher closed).
- Claude works through the inbox/events files and sometimes remote screen control. Windows blocks remote
  input to a frozen window and to Task Manager.

## Process
- Changes ship on `main`, then the player installs a build in the live game.
- Plans and code get independent reviews before install.
